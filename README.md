## 📌 نبذة عن المشروع (Project Overview)

يهدف هذا المشروع إلى دراسة انتشار جائحة كوفيد-19 عالمياً والتنبؤ بالحالات اليومية الجديدة لكل دولة استناداً إلى البيانات التاريخية الوبائية، مؤشرات التشدد الحكومي، والتوزيع السكاني، بالإضافة إلى تحليل شامل لمسارات التطعيم ومعدلات الوفيات.

يوفر التطبيق واجهة مستخدم رسومية تفاعلية تتضمن وضعين رئيسيين:
1. **نموذج التنبؤ (Model Prediction)**: تدريب وتقييم خوارزمية **Gradient Boosting Regressor** مع مقارنتها المباشرة بخطوط الأساس الإحصائية، مع تحكم كامل بالمعاملات الفائقة (Hyperparameters).
2. **التحليل الاستكشافي للبيانات (Exploratory Data Analysis - EDA)**: رسومات بيانية تفاعلية، خرائط حرارية جغرافية، ومتابعة سير عمليات التلقيح ومعدلات الفتك.

## 🤖 نماذج التنبؤ وخطوط الأساس (Forecasting Models & Baselines)

تم تزويد النظام بنموذج تعلم آلة رئيسي مدعوماً بخطي أساس إحصائيين لتوفير تقييم علمي عادل ومقارن:

1. **نموذج التدرج الشجري المعزز (Gradient Boosting Regressor)**:
   - خوارزمية انحدار شجرية تستخدم دالة الخسارة القوية **Huber Loss** لمقاومة القيم المتطرفة والتقلبات الحادة في المنحنيات الوبائية.
   - التنبؤ بالمقياس اللوغاريتمي $\log(1 + y)$ لمنع القيم السالبة وتخفيف الالتواء الإحصائي، ثم إعادة القيم للمقياس الفعلي عبر $\exp(y) - 1$.
2. **خط أساس الاستمرار الساذج (Naive Persistence Baseline - `NaivePersistenceModel`)**:
   - نموذج استمراري يتنبأ بحالات اليوم التالي بناءً على آخر قيمة مسجلة لليوم السابق مباشرة: $\hat{y}_{t} = y_{t-1}$.
3. **خط أساس المتوسط المتحرك الأسبوعي (7-Day Moving Average Baseline - `MovingAverageModel`)**:
   - يتنبأ بالاعتماد على متوسط الأيام السبعة الماضية فقط: $\hat{y}_{t} = \frac{1}{7} \sum_{k=1}^{7} y_{t-k}$.

### 📊 النتيجة التجريبية للتقييم والمقارنة (Empirical Evaluation Finding)
> [!NOTE]
> أظهرت نتائج التقييم المقارن تفوق **خط أساس المتوسط المتحرك الأسبوعي (7-Day MA)** على نموذج **Gradient Boosting** في الدول ذات التقلبات الوبائية الكبرى (على سبيل المثال: في الولايات المتحدة حقق المتوسط المتحرك معامل تحديد $R^2 = 0.7078$ مقارنة بـ $R^2 = 0.0522$ لنموذج GBR).  
> **التفسير العلمي**: نماذج الأشجار القرار لا يمكنها استقراء قيم خارج النطاق الأقصى الذي شاهدته أثناء التدريب (Extrapolation Ceiling)، فتصل إلى سقف ثابت عند حدوث موجات تسارع قياسية جديدة (مثل موجة أوميكرون)، في حين يتكيف المتوسط المتحرك الأسبوعي تلقائياً وبشكل ديناميكي مع التسارع الهيكلي للوباء.

## 🛡️ معالجة تسريب البيانات والهندسة الزمنية (Leakage Remediation & Temporal Engineering)

خضع خط المعالجة البرمجي لفحص تدقيقي شامل لإلغاء كافة أشكال تسريب البيانات الزمني والمستهدف:

1. **إلغاء تسريب الهدف المعاصر (Elimination of Target Leakage)**:
   - تم تعديل المتوسطات المتحركة (`rolling_avg_1` و `rolling_avg_7`) لتكون متأخرة بفارق يوم واحد حصرياً:  
     `df['new_cases'].shift(1).rolling(window).mean()`  
     وبذلك لا تدخل ملاحظة اليوم المستهدف $y_t$ في حساب أي ميزة مدخلة للتنبؤ بنفس اليوم.
2. **تأخير المتغيرات التراكمية والسياسية المعاصرة (Lagged Contemporaneous Covariates)**:
   - تم تأخير `total_cases` و `stringency_index` بفارق يوم واحد (`shift(1)`) لضمان عدم اطلاع النموذج في لحظة التنبؤ على أرقام أو سياسات لم تعلن إلا في نهاية اليوم نفسه.
3. **الترتيب الزمني وعزل الدول (Chronological Isolation)**:
   - فرض تحويل التواريخ بصيغة `datetime` والفرز القطعي المسبق `sort_values(['location', 'date'])`، مما يمنع انتقال البيانات بين الدول أثناء عمليات الإزاحة الزمنية (`shift`).
4. **تصحيح معالجة القيم المتطرفة (Outlier Preprocessing Remediation)**:
   - تم إيقاف الاقتطاع المئوي العام للقيم المتطرفة أثناء التنبؤ (`filter_outliers=False` كخيار افتراضي)، لأن الاقتطاع المئوي عبر كامل السلسلة الزمنية كان يحذف قمم الموجات الوبائية الحقيقية (حذف 70% من أيام الموجات القصوى). وأصبح تعلم الحدود محصوراً ببيانات التدريب فقط عبر `fit_outlier_bounds` و `apply_outlier_bounds`.
5. **معالجة فجوات التقارير الوبائية (Surveillance Gap Handling)**:
   - التواريخ المفقودة في السجلات الوبائية ناتجة في الغالب عن تأخر البلاغات الإدارية وعطلات نهاية الأسبوع وليس انقطاع الفيروس بيولوجياً.  
   - توفر دالة `reindex_daily_calendar()` خيارين: النموذج الافتراضي المبرر صراحة (`fill_strategy='zero'`)، أو التوزيع الخطي للفجوات (`fill_strategy='interpolate'`)، مع إطلاق تنبيه تحذيري توثيقي (`UserWarning`) لمنع التفسير الصامت للبيانات.
6. **دالة عزل لحظة التنبؤ المستقبلية (Forecast-Origin Isolation Helper)**:
   - أضيفت دالة `construct_forecast_origin_features()` التي تبني صف الميزات لليوم $T+1$ بالاعتماد الصارم على البيانات المتاحة حتى اليوم $T$ دون الحاجة لأي مشاهدة أو قيمة مستهدفة لليوم $T+1$.
   - **ملاحظة توثيقية**: هذه الدالة تعمل حالياً كأداة برمجية موثوقة في النواة؛ بينما تم تأجيل واجهة التنبؤ التفاعلي بالمستقبل (Interactive Future Forecasting) والتنبؤ متعدد الآفاق (Multi-Horizon Forecasting) رسمياً إلى **المرحلة 1B (Phase 1B)**.

## ✨ المميزات الرئيسية (Key Features)

- 🎛️ **تخصيص تدريب النموذج من الواجهة**:
  - اختيار الدولة المطلوبة من القائمة المنسدلة.
  - تحديد نسبة تقسيم بيانات التدريب والاختبار الزمني (Train/Test Split).
  - ضبط معاملات التدريب: عدد الأشجار (`n_estimators`)، معدل التعلم (`learning_rate`)، والعمق الأقصى للأشجار (`max_depth`).
- 📊 **جدول مقارنة شامل مع خطوط الأساس**:
  - مقارنة نتائج Gradient Boosting جنباً إلى جنب مع **Naive Persistence** و **7-Day Moving Average**.
  - متوسط الخطأ المطلق (**MAE**).
  - الجذر التربيعي لمتوسط مربع الخطأ (**RMSE**).
  - معامل التحديد (**R² Score**).
  - مقياس الخطأ النسبي المتماثل المعدل (**Adjusted SMAPE**).
- 📈 **تصورات بيانية تفاعلية متقدمة (Plotly & Matplotlib)**:
  - رسم بياني يقارن الحالات الحقيقية بخط الأساس للمتوسط المتحرك لأعلى 5 دول.
  - مقارنة الحالات الحقيقية بالمتوقعة (Actual vs Predicted).
  - مخطط توزيع الأخطاء (Prediction Error Distribution).
  - أهمية الميزات في النموذج (Feature Importance).
  - خريطة جغرافية عالمية تفاعلية (Choropleth World Heatmap).
  - تحليل حملات التطعيم العالمية ومعدلات الفتك عبر الزمن.

## 🚀 طريقة التثبيت والتشغيل (How to Run)

### 1. المتطلبات المسبقة
- تثبيت بايثون إصدار **Python 3.9** أو أعلى (تم التحقق والاختبار على Python 3.11).

### 2. تثبيت المكتبات المطلوبة
```bash
pip install -r requirements.txt
pip install -r requirements-dev.txt
```

### 3. تشغيل التطبيق
```bash
streamlit run main.py
```
سيفتح التطبيق تلقائياً في المتصفح على العنوان: `http://localhost:8501`.
