## 📌 نبذة عن المشروع (Project Overview)

يهدف هذا المشروع إلى دراسة انتشار جائحة كوفيد-19 عالمياً والتنبؤ بالحالات اليومية الجديدة لكل دولة استناداً إلى البيانات التاريخية، مؤشرات التشدد الحكومي، والتوزيع السكاني، بالإضافة إلى تحليل شامل لحملات التطعيم العالمية ومعدلات الوفيات.

يوفر التطبيق واجهة مستخدم رسومية تفاعلية تتضمن وضعين رئيسيين:
1. **نموذج التنبؤ (Model Prediction)**: استخدام خوارزمية **Gradient Boosting Regressor** للتنبؤ بالإصابات اليومية المستقبلية مع تحكم كامل بالمعاملات (Hyperparameters).
2. **التحليل الاستكشافي للبيانات (Exploratory Data Analysis - EDA)**: رسومات بيانية تفاعلية، خرائط حرارية جغرافية، مصفوفة ارتباط، ومتابعة سير عمليات التلقيح.

## 🧹 معالجة وتنظيف البيانات (Data Preprocessing & Cleaning)

تمت معالجة وتنظيف وهندسة البيانات بدقة عالية باستخدام مكتبتي **Pandas** و **NumPy** وفق الخطوات التالية:

1. **معالجة القيم المفقودة (Handling Missing Values)**:
   - تم استخدام `fillna(0)` لتعويض القيم الفارغة في الحالات الجديدة بالصفر.
   - تطبيق الملء الأمامي `ffill()` لمعالجة الفجوات الزمنية وضمان تسلسل البيانات دون انقطاع.

2. **معالجة القيم الشاذة والمتطرفة (Outlier Detection & Removal)**:
   - تم استخدام الحساب الإحصائي للشرائح المئوية (Quantiles) عبر `pandas.Series.quantile()` لتحديد وحصر النطاق الطبيعي للبيانات بين الشريحة 5% والشريحة 95% لإزالة القراءات الشاذة الناتجة عن أخطاء التسجيل أو تراكم البلاغات.

3. **التحويل اللوغاريتمي للهدف (Log Transformation)**:
   - تم تطبيق دالة `np.log1p()` على عدد الحالات الجديدة لتطبيع التوزيع الإحصائي التراكمي وتخفيف أثر التباين الكبير (Skewness)، ثم إعادة القيم للمقياس الأصلي عند التقييم باستخدام `np.expm1()`.

4. **هندسة الميزات الزمنية (Feature Engineering)**:
   - **ميزات الفارق الزمني (Lag Features)**: حساب الحالات السابقة لفارق يوم واحد و 7 أيام (`lag_1`, `lag_7`) عبر تجميع كل دولة على حدة `groupby('location')`.
   - **المتوسطات المتحركة (Rolling Averages)**: احتساب المتوسط المتحرك لـ 1 و 7 أيام (`rolling_avg_1`, `rolling_avg_7`) لالتقاط الاتجاهات الأسبوعية وتأثيرات عطلات نهاية الأسبوع.
   - دمج مؤشرات حيوية تشمل: مؤشر الصرامة الحكومية (`stringency_index`)، وحجم السكان (`population`)، وإجمالي الحالات (`total_cases`).

## ✨ المميزات الرئيسية (Key Features)

- 🎛️ **تخصيص تدريب النموذج من الواجهة**:
  - اختيار الدولة المطلوبة من القائمة المنسدلة.
  - تحديد نسبة تقسيم بيانات التدريب والاختبار (Train/Test Split).
  - ضبط معاملات التدريب: عدد الأشجار (`n_estimators`)، معدل التعلم (`learning_rate`)، والعمق الأقصى للأشجار (`max_depth`).
- 📊 **مقاييس تقييم دقيقة للموديل**:
  - متوسط الخطأ المطلق (**MAE**).
  - الجذر التربيعي لمتوسط مربع الخطأ (**RMSE**).
  - معامل التحديد (**R² Score**).
  - مقياس الخطأ النسبي المتماثل المعدل (**Adjusted SMAPE**).
  - دقة التنبؤ للحالات الكبيرة (**Accuracy for Cases > 10**).
- 📈 **تصورات بيانية تفاعلية متقدمة (Plotly & Matplotlib)**:
  - مقارنة الحالات الحقيقية بالمتوقعة (Actual vs Predicted).
  - مخطط توزيع الأخطاء (Prediction Error Distribution).
  - أهمية الميزات في النموذج (Feature Importance).
  - تحليل الخطأ النسبي (Relative Error vs Actual).
  - خريطة جغرافية عالمية تفاعلية (Choropleth World Heatmap).
  - تحليل حملات التطعيم العالمية وأعلى 10 دول تطعيماً.

## 🚀 طريقة التثبيت والتشغيل (How to Run)

### 1. المتطلبات المسبقة
- تثبيت بايثون إصدار **Python 3.9** أو أعلى (تم التحقق على Python 3.11).

### 2. تثبيت المكتبات المطلوبة
```bash
pip install -r requirements.txt
pip install -r requirements-dev.txt
```

### 3. تشغيل التطبيق
```bash
streamlit run main.py
```
سيفتح التطبيق تلقائياً في المتصفح على العنوان: `http://localhost:8501`.
